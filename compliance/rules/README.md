# Legal Metrology Rule Dataset

This folder contains configurable compliance rules
used by the LegalCheck AI compliance engine.

## Rule Structure

Each rule contains:

- id
- field
- name
- description
- required
- applicability
- severity
- source
- validation_type

## Source

Legal Metrology (Packaged Commodities) Rules, 2011
and applicable amendments/official guidance.

Official source:
Department of Consumer Affairs
https://consumeraffairs.gov.in/pages/legal-metrology-act
